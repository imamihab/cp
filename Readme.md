# Snack Inventory

Sistem Informasi Manajemen Inventori pada UMKM Snack Mbak Tanti.

## Teknologi

- Native PHP
- MySQL / MariaDB
- Bootstrap
- JavaScript
- Apache / XAMPP

## Fitur

- Login pengguna
- Dashboard
- Master kategori
- Master barang
- Stok masuk
- Stok keluar
- Riwayat stok
- Monitoring stok minimum

## Struktur Project

- `auth/` - autentikasi pengguna
- `categories/` - manajemen kategori
- `products/` - manajemen barang
- `stock/` - transaksi stok
- `dashboard/` - dashboard
- `reports/` - laporan
- `config/` - konfigurasi aplikasi
- `includes/` - komponen umum
- `database/` - database schema
- `assets/` - CSS dan JavaScript
